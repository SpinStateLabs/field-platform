## Behaviour change to know about
The old code treated every falsy section as missing (`(x or {})`). The new code treats only a missing or null section as "sets no local_sentinel" and refuses any other non-mapping value, including the falsy ones (`""`, `[]`, `0`, `false`), as "not a mapping". Both are exit 2; the text differs. The tests pin it. HIGH (code and tests).
