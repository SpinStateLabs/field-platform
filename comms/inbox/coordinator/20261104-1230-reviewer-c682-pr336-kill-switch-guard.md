OBJECTIONS FIRST
1. A guard that decodes once and compares text sees the router's view only if every hop decodes the way Python's `unquote` does; any hop that decodes differently (legacy decoders, path parameters, Unicode normalisation) re-opens the hole.
2. Refusing "any path with a self shape, on any host" trades safety for availability: a real agent whose own halt endpoint ends in `/kill` or `/health` gets no halt signal. The PR says so; the cost is real.
3. `trust_env=False` is a blunt switch: it ignores more than proxies.
4. A new counter on a request path that runs in a thread pool; an unlocked `+= 1` can lose updates.
5. Kill-switch code is the "act first, audit later" path; changing what happens on a ledger failure risks turning a best-effort log into a failure of the kill. Checked below.
