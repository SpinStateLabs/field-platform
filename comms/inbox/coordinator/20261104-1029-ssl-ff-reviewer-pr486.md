## Objections first (FORCE-O)
1. BSL 1.1 is not an Open Source licence (the licence's own Notice says so). Publishing under it in a public repository means third parties may read and copy but not use in production; whether that is what the roadmap wants (for example, a customer evaluating in production, or contributors) is a business decision I cannot assess. A source-available licence also cannot be revoked for versions already published (general knowledge, MEDIUM).
2. The repository was public before this licence existed. Copies and versions already obtained without a licence are not changed by this PR; the Change Date and the four-year clock apply to versions distributed under this licence (LICENSE "Terms" paragraph two). I do not know how the earlier history should be treated; ask counsel (not in source).
3. Covenant 4 of the licence says "Not to modify this License in any other way." The PR fills the parameters only, but the Additional Use Grant line reads "None. Production use requires a commercial license from Spin State Labs (don@spinstatelabs.ca)." Covenant 2(b) says to insert the text "None". Adding a sentence after "None" is a common practice but is arguably more than the text "None" (F2).
Steelman: BSL 1.1 with an Apache 2.0 Change License is a widely used pattern, and the parameter block here is complete (Licensor, Licensed Work, Additional Use Grant, Change Date, Change License).
