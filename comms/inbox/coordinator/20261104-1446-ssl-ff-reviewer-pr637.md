## Objections first (FORCE-O)
1. The file asserts `len(SITES) == 16` as a guard that new sites get added, but that counts the test's own table, not the renderer's interpolations: a new `{...}` in `render_html` is not noticed by it. The comment says "new site => add it here", which depends on a human. LOW.
2. `window.kind` is interpolated through `esc()` in render.py line 61 but is not one of the 16 sites; mutant S4 (escape removed there) survives. It is not exploitable today because `Window.kind` is `Literal["quarter", "range", "all-time"]` (window.py:47), so pydantic refuses any other string; I treat S4 as equivalent while the type stays a Literal.
3. The integrity class (`class='integrity-<first token>'`) is built from the metric value without escaping, by design: the engine produces only INTACT and `BROKEN — <reason>`. The test file says so and pins the real values; a hand-built Metric whose value is `INTACT` or `BROKEN` glued to text with no space is not covered, as the docstring states.
Steelman: each of 16 sites has its own test with three assertions (raw payload absent, no `<script`, escaped form present), so a site dropped from the page cannot pass; the unavailable branch and the all-time window are covered; 20 of 22 mutants die.
