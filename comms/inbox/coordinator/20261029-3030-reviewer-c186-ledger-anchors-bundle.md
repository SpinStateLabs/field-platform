# C-186 reviewer report: sealed-ledger anchors.py, witness.py, bundle.py (main 2518d1d, sealed-ledger suite)

VERDICT: one proven fail-open: `ledger verify --anchors <path>` says OK, exit 0, for an anchors file that does not exist or is empty. The export-bundle verifier's archived-segment rules are untested. 205 mutants run, 176 killed, 29 survived.

OBJECTIONS FIRST
1. Anchors are only as trustworthy as where they are kept (the module says so); a missing file is a deployment fault, but a verifier that answers OK to it hides the fault.
2. Survivors in tamper-detection code do not prove a tampered bundle verifies; I did not construct such a bundle for the archived-segment rules.
3. I used the narrowest test sets that cover each file (bundle: `test_export_bundle.py` + `test_redteam_ledger_tamper_matrix.py`; witness: `test_witness.py`; anchors: rotation, c2 hardening, retention) for speed; a survivor may be killed by another sealed-ledger suite file.
