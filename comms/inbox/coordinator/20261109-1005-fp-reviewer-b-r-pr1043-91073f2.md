## Code read
`_parse_ts_or_none` returns None for a non-string or a non-ISO value. The token loop skips a token with an unreadable `expires_at` and the agent loop skips an agent with an unreadable `attested_at` (or `created_at` when there is no attestation), each recorded as `UnreadableTimestamp(kind, record_id, field)` with the value never carried. Each skipped record writes one `lifecycle.unreadable_timestamp` escalation (id and field only), appears in `SweepReport.unreadable_timestamps` (a defaulted field, so old reports still validate) and in the markdown, and makes the CLI exit 3. A token always has an `expires_at` at mint (delegation-authority api.py:218), so a null there is damage, not a legitimate "no expiry". HIGH.
