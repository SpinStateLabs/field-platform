OBJECTIONS FIRST
1. An allow-list built on `urlparse` can differ from what the HTTP client connects to (parser differential); an allow-list that accepts "any single-label name" accepts every spelling the resolver turns into an address.
2. The IPv4-mapped IPv6 result depends on the Python patch level; I ran 3.12.3 only; CI runs 3.11 to 3.14.
3. A hostile `ANTHROPIC_BASE_URL` is set by whoever controls the environment; the allow-list is a misconfiguration guard, not a defence against that actor.
