## Code read
`export` now opens the store inside the try, maps `LedgerBusy` (and its subclass `LedgerUnreadable`, store.py:163) to `_busy` (exit 4; UNREADABLE without "retry" for the permission case), maps `LedgerCorrupt` and `ValueError` to exit 1 with only the class name, and keeps `InvalidTimeBound` / `InvalidSigningKey` (both ValueError subclasses) as exit 2 because their clause comes first. The existing `OSError` clause is unchanged.
