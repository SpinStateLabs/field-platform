## C-16 line-by-line read: findings (probes in ~/ff-work/probe57, no network)
1. MEDIUM, PROVEN: a crash right after `_write_operators` in `_migrate` leaves `keyrotation.reconciled` never ledgered. Probe: hook raises at after_operators_write on a format-1 file; the next `run_once()` returns `nothing_due` and `bed.estate.of("keyrotation.reconciled")` is empty. `_migrate` builds a Journal but never saves it (rotation.py ~1217-1256); recovery relies on the status file's `pending_sha256`, which accepts the file without ledgering the generation step. Breaks "every generation step has its event" (rotation_events docstring). Fix: save a journal at phase publish before the write; on resume, if the live sha equals pending, emit `reconciled`.
2. MEDIUM, PROVEN: `_check_foreign_edit` returns at once when `last_written_sha256` is missing (`if not last or sha == last: return`, ~L1118). Delete or corrupt rotation.status and a foreign edit is accepted: probe edited svc-registry scopes to ["*"] after a completed rotation, deleted the status file, and the next run rotated that identity and kept the edit (scopes still ["*"]). With C-34 part 2 finding 1 (the ledger witness ignores content-only edits) both detectors miss it. Fix: missing status with a live file and a non-zero generation = treat as foreign_edit (or rebuild status only from an explicit `--accept-roster`, which is already R9's plan).
3. LOW: `Settings.services` accepts any non-empty subset of the eight (rotation.py ~261-306); only the CLI forces all eight (operator_rotate.py:184). A library caller (R7 Fly loop) could verify and promote against fewer services. Make the library enforce `== ev.SERVICES` unless a named test flag.
4. LOW: `_publish` has no compare-and-swap between `_read_live` and `_write_operators`: an edit landing in that window is overwritten (candidate was built from the older read). Re-read and compare the sha just before the rename.
5. LOW: `_write_operators` wraps `os.chmod` in `suppress(OSError)`; a failed chmod leaves the new file 0600 where services read it through a read-only mount as another uid (~L489-509). Fail the write or verify the mode.
6. LOW: `_soak` aborts the whole rotation on ONE failed daemon fingerprint read (`_daemon_fp` returns None on EstateError, `None != new_fp`, ~L1521): a transient /rotation-state error during the 24 h soak rolls the rotation back and, repeated, prevents any rotation. Require N consecutive misses.
7. LOW: `_resume` with another identity in flight reports `skip_reason: lock` (`_skip("lock", ...)`, ~L1085); it is not the lock. Cosmetic, but alerts on `lock` will mislead.
8. INFO: P5 is a TOCTOU defence-in-depth guard (corrects my first note on #57).
9. Not found: no key/hash printed or journaled (journal holds fingerprints only; `.next` created 0600 O_EXCL; umask 077 in run_once); POST_PROMOTE_RETRY has no cap (D-5, already recorded); hard-link fallback in `_switch` fails closed with `io`.
