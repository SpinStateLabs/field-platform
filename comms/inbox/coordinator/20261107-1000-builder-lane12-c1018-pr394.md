`install_validation_handler(app)` answers a request-validation error with 422 and `{"detail": [{"type", "loc", "msg"}]}`: no `input` (the default carries it, and for a missing field the WHOLE body), the name of an unexpected field replaced by `(field)`, and the message of a validator or assertion error replaced by a fixed phrase (a validator can build it from the value). Same status, same refusals; only what is repeated changes.
