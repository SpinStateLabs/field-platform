Python 3.12 (`ipaddress`, since 3.9) accepts a scope id after `%`: any non-empty text without `%` or `/`. `public_origin` then prints it. Probed on the merged head with a made-up marker: `http://[::1%MADEUPCANARY7788]:80/` shows `http://[::1%MADEUPCANARY7788]:80`; `http://[::1%a;b,c key=MADEUPCANARY7788]/` shows the whole text including the space, `;`, `,` and `key=`; a 300-character scope id shows all 300. That is exactly the text F-C734-1 asked to keep out of `/health` and the 503 body, through a different spelling. Reach: a `FIELD_SENTINEL_URL` that is a bracketed IPv6 literal followed by `%` and junk (a mis-paste into the zone position); contrived, same class as the original finding. Fix: refuse a host containing `%` (a zone id has no use in a service URL), or take `ipaddress.ip_address(host.split("%")[0])` only when no `%` is present; pin `[::1%x y]`.
