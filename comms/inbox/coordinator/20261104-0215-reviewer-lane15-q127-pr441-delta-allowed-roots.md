## FINDINGS
- F-Q127-1 LOW-MEDIUM (`tools/compose_bind_rules.py`, `_root_problem`, and the denylist regexes it uses): the checks are case-sensitive. Measured: `/ETC`, `/Etc/ssl`, `/Proc/x`, `/ROOT/x`, `/Var/Lib/Docker/x` and `/HOME/<acct>/.ssh` are all accepted as roots. On a Linux host those paths do not exist, so it is harmless there; on a case-insensitive filesystem (macOS default, Windows) a case variant of a forbidden tree is the forbidden tree, and a source under such a root would pass because the source denylist is case-sensitive too. The estate is Linux, so low in practice; the variable makes it newly reachable. Pin: compare on the lower-cased path in `_root_problem` and `_denied`, or state "Linux only" in the ENVIRONMENT.md paragraph.
- F-Q127-2 LOW (same function): nothing stops a broad root that is not on the denylist. Measured accepted: `/usr/lib`, `/usr/local`, `/usr/local/bin`, `/lib64`, `/var/log`, `/var/spool`, `/tmp`. A source below any of them becomes bindable. It is the operator's explicit act (the variable is set where the gate runs), so this is a guard-rail gap, not a bypass. Pin: a minimum depth or an allowlist of parents, or one sentence in the security-impact text.
- F-Q127-3 LOW (pin gaps): M3, M11, R5. M3: a carriage return in an entry (cannot occur in a real environment value). M11 and R5 share a gap: runtime sockets. The test's socket entry (`/var/run/docker.sock`) is already refused by the `/var/run` tree rule, so the socket branch of the root validator is never exercised alone, and nothing pins that a socket source UNDER an allowed root stays denied. Measured today: with a root set, sources spelled `.../docker.sock`, `.../sub/containerd.sock`, `.../agent.sock` and `.../S.gpg-agent` are `on the denylist`, an ordinary `.../ok.sock` is allowed, and a root entry that is itself a socket path is refused ("a runtime socket"): the behaviour is right, the pin is missing. Pins: an entry `/data/x/docker.sock` is refused; with the variable set, a source `<root>/docker.sock` is `on the denylist`.
