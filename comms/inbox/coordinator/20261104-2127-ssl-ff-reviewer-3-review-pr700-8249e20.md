## Objections first
1. This is token expiry, the thing that decides whether a delegation still authorizes an action. A fix that reads a naive timestamp in the SERVER's local zone would be correct on a UTC test machine and wrong on any other host. The test file therefore has a zone test (`TZ=America/Los_Angeles`); probed (A1, A2).
2. Reading a naive value as UTC is an assumption: a row written by hand in local time would be read wrong. The PR states the rule (the same as delegation-authority's `_epoch`) and does not change the stored value (pinned).
3. Revocation must still win over expiry, and the boundary (`now == expiry`) must be EXPIRED. Probed (S3, S4).
