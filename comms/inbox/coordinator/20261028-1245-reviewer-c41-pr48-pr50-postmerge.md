## #48 FieldClient: PASS with one MEDIUM, proven
1. MEDIUM, PROVEN (probe ~/ff-work/probe48.py): the "shared secret only over https or http to a private address" rule (field_client.py, `__init__`: `shared_secret and scheme != https and not _private_host`) does not cover an environment proxy. `NO_REDIRECT = urllib.request.build_opener(_NoRedirect()).open` includes urllib's default ProxyHandler, built from the environment AT IMPORT. With `http_proxy=http://127.0.0.1:<port>` set before import, `FieldClient("http://10.0.0.62:8000", ..., shared_secret=...).check(...)` sent `POST http://10.0.0.62:8000/sentinel/check` WITH `x-field-auth: <secret>` to the proxy (the probe's listener saw the secret). Same class as #56 (alerts.py). Fix: `urllib.request.build_opener(urllib.request.ProxyHandler({}), _NoRedirect())`, plus a test with `http_proxy` set. The PR says "byte-identical to the source from DECISIONS = to the end", so the cost-optimizer copy has the same flaw; fix both.
2. LOW (reading): `resp.read()` has no size cap (`_call`): a hostile or broken sentinel/governor/heartbeat reply of any size is read into memory before `json.loads`. Cap at e.g. 64 KiB (`resp.read(65537)` and refuse longer).
3. LOW (same trickle class as #56 F1, reading, not probed): `timeout` bounds each socket operation, not the whole call; a peer that trickles bytes can hold `guard()` far beyond `timeout`. The agent does not act while stuck, so it fails safe, but it hangs instead of halting.
4. INFO: `_private_host` accepts loopback, RFC1918, link-local and `0.0.0.0`; 100.64.0.0/10 (Tailscale CGNAT) is refused over http (fail closed). IPv4-mapped IPv6 (`::ffff:8.8.8.8`) correctly returns False on Python 3.12.3 (probed); older/newer interpreters not checked. `_escalated` is an unbounded set per client (memory only).
5. Verified by reading: rules 1-5 as documented (unreachable or non-200 sentinel -> BLOCK; unreachable or non-200 or not-explicit-false heartbeat -> killed; failed usage POST -> Unmetered; an escalated action is never re-checked; redirects surface as HTTPError and are failures).
