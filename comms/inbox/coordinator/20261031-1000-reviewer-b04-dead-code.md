# B-04 reviewer (Lane 4): dead-code report for packages/ and services/ @ main 5454a8d (report only, nothing changed)

SUMMARY: one function is unreferenced everywhere and keeps a fail-open behaviour that a recent ruling removed from its sibling (`sealed_ledger.anchors.load_anchors`, F-B04-1); a handful of superseded or deprecated functions are called by tests only and keep an older, weaker code path alive (F-B04-2, F-B04-3); five module constants and three imports are unused (F-B04-4, F-B04-5). Everything else the scan flagged is a framework callback or a documented public API, listed so nobody deletes it. No bulk dead code: of 1,617 functions, methods and classes under `packages/*/src` and `services/*/src`, 1,320 survive the framework exemptions and 27 have no live caller from production code.

## OBJECTIONS FIRST (about this report)
1. This is name matching on the AST, not data flow. A function is "referenced" if any `Name`, `Attribute`, import alias, keyword argument or identifier-shaped string constant anywhere in a tracked Python file equals its name. That can only OVER-count references (a method named like a live one is hidden: 101 of the 1,124 distinct names are defined more than once, for example `post`, `get`, `check`, `rotation_state`, `redirect_request`, `auth_flow`), so the real dead set is a superset of what I list. Dynamic dispatch by a name built at run time (string concatenation, `getattr` on a computed name) would make a live function look dead; I found none among the candidates (each was checked by hand with `git grep -w`). MEDIUM on completeness, HIGH on each listed item.
2. `vulture` is not installed on the GX10 (`No module named vulture`), so I wrote the scan myself (three AST passes plus a module-constant and unused-import pass; scripts on the GX10 under `~/ff-work/c195/dead`, not committed). I did not compare against vulture's output.
3. Scope: only `packages/*/src` and `services/*/src` (123 Python files), as the card says. `tools/`, `defence-shield/`, `plugins/`, `agents/`, `integration/` scripts and the tests were used as REFERENCE sources, not scanned for dead code. Class attributes, instance attributes, pydantic fields, enum members and dead branches are not covered.
