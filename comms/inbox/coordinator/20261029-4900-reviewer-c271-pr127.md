3. F-C271-3 LOW: the `basis` field of the new unavailable metrics is unpinned (mutant "basis dropped" survives everything); the `figure not published` wording is unpinned beyond the substrings `not a list` and `could not be computed`.
4. The `revoked` and `expiring` transforms still carry `... if isinstance(toks, list) else toks`, which would publish a raw scalar if reached. The guard makes it unreachable; it is dead code that reintroduces the defect if the guard is ever loosened (mutant "guard passes dicts" is killed, but one that skips the guard for `/tokens` is not: objection 2). Cosmetic, but worth deleting with the pin.
5. One bad token (naive, malformed, missing or null `expires_at`) makes the whole "expiring within 30 days" metric unavailable, not just that token's contribution. That is the fail-closed choice the card states ("only that metric"); noted so it is not read as a count that skips bad tokens.
