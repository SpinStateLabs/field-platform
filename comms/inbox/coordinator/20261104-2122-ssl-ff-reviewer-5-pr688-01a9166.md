2. The `contract_id` is percent-encoded in the PUT path (`quote(contract_id, safe="")`), so an id with a slash becomes `%2F`; the tests pin that an id with a slash or an escape gets a clean 404 and not a traceback, not that the broker could ever store one. 3. The unreachable handler catches `httpx.HTTPError` and `InvalidURL` only; any other exception type (a `ValueError` from a malformed header, an `OSError` outside httpx) is still a traceback. The `_HTTP_ERRORS` tuple is captured at import because the tests replace the module's `httpx` with a stub; a comment states it. LOW.
4. Non-JSON error bodies are collapsed to one line and capped at 200 characters; the cap's lower side is not pinned (below).
