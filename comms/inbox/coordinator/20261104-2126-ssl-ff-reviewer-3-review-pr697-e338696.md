## Objections first
1. The deployment agent's manifest is a refusal gate: a manifest that crashes the loader fails closed by accident, one that loads with a wrong shape would fail OPEN. The PR makes wrong shapes into `ManifestError` (CLI: `refused:`, exit 2). I tried each shape the fix names and the loosening of each check.
2. "a dead watcher is fail-open without it" (the code's own message): the kill-switch sentinel and its age are what make the gate safe. The sentinel was checked with `not sentinel`; a list or mapping passed. Probed (S1-S3).
3. The messages carry the exception CLASS only, by design; the tests do not check that (E4-E6 survive).
