## Objections first (FORCE-O)
1. Content is rewritten, not only fenced: `one_line` turns every `|` into a space and collapses whitespace, so a declared manifest value `Controller | injected | cells` is published as `Controller injected cells` in the JSON AND the Markdown (pinned by the last test). The signed evidence therefore no longer quotes the manifest byte for byte. Deliberate ("so the two never disagree") but it is a change to what an auditor sees; a value that legitimately contains `|` loses it (LOW; HIGH that this is the behaviour).
2. Other interpolation sites remain: the pack prints `generated_at` and `corpus_version` unfiltered (evidence_pack.py:192-193), and the report prints `generated_at` and `report.citation_status` (engine.py:245, 251). `generated_at` is the clock; `corpus_version` and `citation_status` come from the store and the mapping, not from the caller or a service answer, so I treat them as trusted, but I did not trace `corpus_version` back to its file (not verified; LOW).
3. The pinning of the line-break classes is weaker than it looks. In `one_line` the characters Zl, Zp (U+2028/2029) and the C0 whitespace controls are removed by `str.split()` anyway, so the `REFUSED_CATEGORIES` entries Zl and Zp are redundant THERE (mutants M9/M9b do not change `one_line`'s output); they matter for the signer refusal, which the existing signer tests pin (both mutants: 2 failed in the whole suite). A NON-whitespace control (NUL, ESC, BEL) is the only case where `Cc` does work in `one_line`; this file never sends one, so M7 survives the PR's file; the whole suite kills it only through the signer tests (34 failed). Measured: the head turns "a\x1bb\x00c\x07d" into "a b c d", while the M7 mutant leaves the raw bytes. LOW test gap: add one NUL/ESC case.
4. `AGENT_ID_MAX` is imported into the test from the module, so the bound test is self-adjusting: a limit one too high (M15, 201) passes the PR's file and the whole crosswalk suite (445 passed). Likewise two pattern mutants that widen only a NON-first character (M20 allows `?`, M22 allows `é` and `\w`) survive, because each BAD id also fails on another character (`a?b=1` has `=`; `é` fails the first-character class). LOW.
Steelman: three interpolation sites (report H1, pack `agent_id` line, ledger `reason` in the controls table and gap bullet) let a caller or a service answer add a heading, a table row, a `Signer:` line or a signature block to a document that carries a named human's signature; and `collect_evidence` put the same id into URL paths and queries. Now each is one line, the JSON carries the same cleaned text, and the API refuses an id outside the registry's grammar with a 422 that does not echo it.
