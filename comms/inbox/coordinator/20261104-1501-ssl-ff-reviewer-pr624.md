## Objections first (FORCE-O)
1. The test fixture patches `cli._client` with a lambda that accepts `pair` and discards it. Any wiring error between a verb and its client (pair, timeout) is therefore untestable in this file; that is where mutants U13 to U16 got through.
2. Id quoting is pinned for three verbs (`heartbeat`, `agent`, `domain`); `drill`, `revive` and `checkin` also quote their id and nothing proves it (Q6, Q7, Q9 survived). `revive` and `drill` are state-changing.
3. Only `httpx.ConnectError` is exercised for the "unreachable" refusal; a timeout (`ReadTimeout`) or any other `httpx.HTTPError` subclass is not (U2). The code catches the base class, which is right; the test would not notice a narrowing.
Steelman: the refactor is sound (one `_request` helper, one `_q` quoting function, one `_killed` parser), the unreachable case never prints the URL, headers or exception text (tested with a marker for all seven verbs), the quoting test uses the nastiest path characters (`?`, `#`, `/`, `..`), and a 200 with a non-object body is a named exit 1; 24 of 34 mutants die.
