The skip is the test's own guard (HIGH).

The proxy-lint allowlist line moves from `run::httpx.post = 2` to `= 1` because the two calls became one; I ran the proxy-allowlist tests under tools/tests (`-k "proxy_allowlist or http_env_proxy"`): 102 passed, 3 skipped. Steelman: before the change `replay run` with the service down, an HTML error page (dumped whole, 300 lines in the test) or an unwritable `--markdown` path raised a traceback or printed a page of HTML, and the markdown file could be created before the status check; now each is one line with a fixed exit code (1 for service trouble, 2 for a write failure), the file is written only after a 200, and when the file cannot be written the post-mortem is printed to stdout instead of being lost.
