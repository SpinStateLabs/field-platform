## What it does
`field_core.http.client(*, timeout, **kw)` and `async_client(...)`: `trust_env=False` and `follow_redirects=False` as literals on the call (the C-57 lint reads them there; the allowlist did not grow); timeout REQUIRED and refused when None, zero, negative, non-finite, a bool, or an `httpx.Timeout` with any None or zero part; `trust_env`, `follow_redirects`, `proxy`, `proxies`, `mounts`, `transport`, `event_hooks`, `cert` cannot be passed; `verify` only as `True` or an `ssl.SSLContext`; the one proxy is `FIELD_EGRESS_PROXY` (an http or https URL with a host; a bad value raises without echoing it); documented in docs/ENVIRONMENT.md.
Card question "what does trust_env=False turn off besides the proxy": in httpx 0.28.1, `SSL_CERT_FILE` and `SSL_CERT_DIR` are no longer read when `verify` is left default (httpx/_config.py:34-37); nothing else found (netrc is an explicit auth class). A call site that relied on those variables for a private CA must pass an `ssl.SSLContext` through `verify=` when it migrates. Read for 0.28.1 only; the dev pin is `httpx>=0.27` (MEDIUM).
Tests: 83 in packages/field-core/tests/test_http_client_c487.py: a stock `httpx.Client` DOES hit a local proxy listener (control), this client never does (sync and async); redirects returned not followed; every timeout and pin rule; explicit proxy used; bad proxy refused and never echoed.
